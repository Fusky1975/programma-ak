{{ kingdom.name }} — Compose Moves for Turn {{ state.turn_number }}

A base editor, filled in one Action (and, for Search, one Encounter Plan tactic) at a time: Move has its own destination dropdown, Explore needs no input at all (it always targets the leader's own current province), Search has its own target-feature dropdown plus Encounter Plan tactic slots (Talk, Fulfill, Say, Steal, Flee, Scout, Cast, and Use Item so far have their own rules wired in, the Search Encounter Plan's own Give tactic and Beg are excluded entirely -- only Shoot and Melee, which take no sub-object at all, are still undesigned), Recruit has its own commander dropdown plus repeated army-type slots (cost/limit/ mercenary preview only -- the engine is still the real arbiter at turn-processing time), Disband has its own repeated army-target slots (pre-filtered to exactly what this leader could actually Disband) plus a "Disband ALL I command" pseudo-option in the first slot, Leave has its own "to" dropdown (another co-located, allied leader, or the Garrison Commander) plus the same repeated army-target slot shape as Disband, Pick Up has the same repeated army-target slot shape too (no separate target dropdown -- it always acts for the ordering leader himself), Give (the Action internally still named "Trade" -- see below) has its own recipient dropdown plus a gift dropdown (an owned item, or Gold with a free-text amount), Practice has its own single Talent dropdown, Trail has its own single target dropdown (any other leader in the game, no co-location needed), Challenge (the engine's own internal name for "Encounter Character," wire code "EN") has its own target dropdown (co-located leaders only) plus the same Encounter Plan tactic slots Search uses, Give included (valid only here and after Pursue, never in Search), Pursue has its own target dropdown (any other leader, no co-location needed -- same shape as Trail's) plus the same Encounter Plan tactic slots as Challenge, used if/when the chase actually catches up; an armyless Pursue is rejected here unless at least one tactic is filled in, since the rulebook requires an Encounter Plan in that case (the engine itself stays permissive about an already-saved empty one), Hire has its own free-Hero target dropdown plus a 1-4 gold-offer dropdown, plus a basic editor for the hired Hero's own orders for the rest of this turn (starting the phase right after the Hire, up to P4 -- plain generic Action/Object/Extra fields for now, not yet the full per-Action composer), Fire has its own target dropdown (own-Kingdom Heroes only, co-located unless this leader is a King, "Self" always included), Cast has its own spell dropdown (19 Action spells, Gate Angel excluded -- combat-tactic use only) plus whichever target field matches that spell's own shape (character/province/item/none, or Resurrection's/Charm's/Kill Enemy's own more elaborate, accurately-filtered target lists -- Charm's own list includes any Kingdom, poaching included, plus an Undead-King-only conversion note; Kill Enemy's own list excludes Kings and Undead targets but, unlike Charm, still includes an army-leading Hero with a halved-chance note, since that only penalizes the roll rather than blocking it outright), with the same nested-plan editor Hire uses for a successful Charm or Resurrection; every other Action still takes the same plain Object + Extra numbers a real move file's own "P<n> : <action> <object> <extra...>" line carries. Saving builds a real move file from these and stores it exactly like an uploaded one.

The Action dropdown shows "Give" where the engine's own internal name is "Trade" -- a real naming mismatch confirmed in the original Pascal source (its own two-letter abbreviation table gives this Action "GI," matching the rulebook's Give order [3.18]; the rulebook's own "Trail (TR)" is a separate, not-yet-designed Action).
