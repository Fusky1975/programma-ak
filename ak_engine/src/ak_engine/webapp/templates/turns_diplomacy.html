Treat / Break Treat Orders — Turn {{ state.turn_number }}

Rulebook [8.2]/[8.3]: a Treat order promotes the relation one step (Enemy → Neutral → Allied), but only if both Kings issue it toward each other this turn. A Break Treat order demotes it one step unilaterally (straight to Enemy if both sides issue it on a currently-Allied pair). A Treat order is also what lets your ally recruit in your own territory this turn, even if you're already allied.

A King may try a Treat (or a Break Treat) toward several other Kingdoms the same turn -- tick as many as apply in each list below.
