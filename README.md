# Programma AK — Adventurer-Kings

Materiali e documenti di progettazione per il gioco Adventurer-Kings.

## Contenuto della cartella

- [`Mostri.md`](Mostri.md) — elenco completo dei mostri, statistiche e assegnazione ai Luoghi Speciali
- [`Oggetti Magici.md`](Oggetti Magici.md) — tabelle di tesori e oggetti magici (passivi e a cariche)
- `Regolamento AK.doc` — regolamento completo del gioco
- `Scrittura gioco.txt` — appunti e bozze di scrittura
- `Programma Pascal.zip` — sorgenti del programma in Pascal
- [`ak_engine/`](ak_engine/README.md) — riscrittura moderna in Python del motore di gioco (in corso, a fasi)
- `files.zip` — archivio dati aggiuntivo
- `AK3__T*.K1`, `GW3__T*`, `SE3__T*.K1` — file dati delle varie serie/turni del gioco
